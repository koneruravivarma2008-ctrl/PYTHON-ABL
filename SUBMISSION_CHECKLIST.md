# ABL Submission Checklist

Use this checklist before submitting the Python ABL assignment.

## Student details
- [ ] Name added
- [ ] Roll number added
- [ ] Branch and section added

## For each of the 10 projects
- [ ] Program matches a topic approved by the faculty from the official list of 100 case studies
- [ ] Source code runs successfully
- [ ] Algorithm included
- [ ] Pseudocode included
- [ ] Flowchart drawn with standard symbols
- [ ] Test cases and expected results included
- [ ] Genuine output screenshot captured
- [ ] Conclusion included
- [ ] Program can be explained during viva

## Final repository
- [ ] Root README reviewed
- [ ] All 10 project folders have a `main.py` and a `README.md`
- [ ] Consolidated PDF report uploaded
- [ ] Student details are correct
- [ ] Repository URL submitted to the Python Programming faculty member or lab mentor

## Run a project
Open a terminal inside its folder and run:

```bash
python main.py
```

On some systems use `python3 main.py`.

**Important:** The repository contains suggested syllabus-aligned programs. Confirm the final topic selection against the faculty's prescribed list before submission.
