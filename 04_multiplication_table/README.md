# Multiplication Table Generator

## Syllabus concepts
Unit II: for loop, range(), arithmetic operators, formatted strings.

## 1. Problem statement
Print the multiplication table of a number from 1 through 10.

## 2. Objectives
Use a for loop to repeat calculations and format output.

## 3. Assumptions
The user enters an integer.

## 4. Algorithm
1. Start.
2. Read an integer.
3. Repeat i from 1 to 10.
4. Calculate and display number multiplied by i.
5. Stop.

## 5. Pseudocode
```text
INPUT number
FOR i from 1 to 10:
    DISPLAY number, 'x', i, '=', number * i
END FOR
```

## 6. Flowchart
Start → Read number → Loop i = 1 to 10 → Calculate and display product → Loop ends → Stop

Suggested symbols for a hand-drawn flowchart: oval for Start/Stop, parallelogram for input/output, rectangle for processing, and diamond for decisions.
