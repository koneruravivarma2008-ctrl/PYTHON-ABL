## Syllabus mapping

- **Unit I:** Variables, data types, input/output, type conversion, operators, expressions.
- **Unit II:** if/elif/else, loops, strings, string methods, formatting, pattern generation.
- **Unit III:** Lists, tuples, tuple unpacking, sets, set operations, membership testing.

## How to run

Install Python 3, open a terminal in a project folder, and run:

```bash
python main.py
```

On some systems, use `python3 main.py`.
