# Student Academic Dashboard – Algorithm and Pseudocode

## Aim
Display sample student academic information: attendance, semester marks, examination schedule and announcements.

## Algorithm
1. Start.
2. Create the HTML document and link the external CSS file.
3. Create the header and navigation links.
4. Add the main page sections: Student overview and summary cards, Semester results table, Attendance by subject, Examination schedule, Campus announcements.
5. Apply CSS colors, typography, images, dimensions, borders, margin, padding and responsive layout.
6. Use anchor links to navigate to page sections.
7. Open the page in a browser and check links, images and layout.
8. Stop.

## Pseudocode
```text
BEGIN
LOAD HTML document and external CSS
DISPLAY header and navigation
DISPLAY Student overview and summary cards; DISPLAY Semester results table; DISPLAY Attendance by subject; DISPLAY Examination schedule; DISPLAY Campus announcements
APPLY CSS presentation and responsive rules
WHEN a navigation link is selected, MOVE to its matching section
END
```
