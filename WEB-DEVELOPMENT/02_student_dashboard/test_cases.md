# Student Academic Dashboard – Test Cases

**Testing type:** Manual functional and visual testing.

| Test ID | Test step | Expected result | Verification |
|---|---|---|---|
| TC01 | Open index.html | Dashboard and student profile appear | Manual visual check |
| TC02 | Select Semester Results | Results table is reached | Subject, code, marks and grade columns appear |
| TC03 | Select Attendance | Attendance bars and percentages appear | All listed subjects are visible |
| TC04 | Select Exam Schedule | Exam dates and details appear | Schedule list is visible |
| TC05 | Select Announcements | Announcement list is reached | Sample notices appear |
| TC06 | Resize browser to mobile width | Sidebar and content stack vertically | Text remains readable |

**Important:** These are test procedures and expected results, not claimed pass results. Perform them in a browser and record Pass/Fail. This is a static HTML/CSS demonstration; it does not store or submit user data.
