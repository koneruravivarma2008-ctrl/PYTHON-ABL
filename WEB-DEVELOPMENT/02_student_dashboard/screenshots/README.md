# Screenshot evidence

Genuine browser screenshots are still pending. The automated browser capture was blocked in the execution environment, so no fabricated screenshots are included.

To capture them on your Windows computer:
1. Open `../index.html` in Chrome or Edge.
2. Capture the full desktop page (use a full-page capture feature or `Win + Shift + S`).
3. Resize the browser to a phone-sized width and capture the mobile layout.
4. Save the images here as `desktop.png` and `mobile.png`.
5. Commit both images to this folder.
