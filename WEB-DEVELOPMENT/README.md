# Web Development – Three Case Studies

Three beginner-friendly HTML and CSS projects based on the supplied Web Development syllabus.

1. `01_personal_portfolio/` – Personal Portfolio Website
2. `02_student_dashboard/` – Student Academic Dashboard
3. `03_bakery_shop/` – Bakery and Cake Shop Website

## Run
Open each folder's `index.html` in a web browser. Keep `style.css` beside it. Images use remote Unsplash URLs and need an internet connection.

## Syllabus coverage
HTML document structure, elements, headings, paragraphs, links, images, lists, classes, containers, CSS syntax and rulesets, text alignment and colors, backgrounds, fonts, borders, box model, width, height, margin, padding, viewport, anchor navigation and responsive/mobile-first layouts.

Note: All student records, grades, dates, bakery prices and contact details are demonstration content. Replace them before submission. No JavaScript, backend or real authentication/ordering is included.
