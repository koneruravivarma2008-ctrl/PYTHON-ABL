# Web Development – Three Case Studies

Three beginner-friendly HTML and CSS projects based on the supplied Web Development syllabus.

1. `01_personal_portfolio/` – Personal Portfolio Website
2. `02_student_dashboard/` – Student Academic Dashboard
3. `03_bakery_shop/` – Bakery and Cake Shop Website

## Included in each project
- `index.html` – webpage structure and content
- `style.css` – styling and responsive layout
- `algorithm_pseudocode.md` – aim, algorithm and pseudocode
- `flowchart.md` – Mermaid flowchart
- `test_cases.md` – manual test steps and expected results
- `screenshots/README.md` – instructions for adding genuine desktop and mobile execution screenshots

## Run
Open each folder's `index.html` in a web browser. Keep `style.css` beside it. Images use remote Unsplash URLs and need an internet connection.

## Syllabus coverage
HTML document structure, elements, headings, paragraphs, links, images, lists, classes, containers, CSS syntax and rulesets, text alignment and colors, backgrounds, fonts, borders, box model, width, height, margin, padding, viewport, anchor navigation and responsive/mobile-first layouts.

## Screenshot status
Actual browser execution screenshots have **not** been uploaded yet. The screenshot folders contain instructions only; no placeholder images are presented as real execution evidence. Capture desktop and mobile screenshots after opening each project in a browser, then add `desktop.png` and `mobile.png` to the relevant `screenshots/` folder.

## Notes
All student records, grades, dates, bakery prices and contact details are demonstration content. Replace them before submission. No JavaScript, backend or real authentication/ordering is included. The test cases are expected-result checklists and should be marked Pass/Fail only after manual testing.
