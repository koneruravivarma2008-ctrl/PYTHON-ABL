# Personal Portfolio Website – Algorithm and Pseudocode

## Aim
Present a student profile, education, skills, projects, achievements and contact information.

## Algorithm
1. Start.
2. Create the HTML document and link the external CSS file.
3. Create the header and navigation links.
4. Add the main page sections: Home / introduction, About me, education and hobbies, Technical skills, Projects and achievements, Contact information.
5. Apply CSS colors, typography, images, dimensions, borders, margin, padding and responsive layout.
6. Use anchor links to navigate to page sections.
7. Open the page in a browser and check links, images and layout.
8. Stop.

## Pseudocode
```text
BEGIN
LOAD HTML document and external CSS
DISPLAY header and navigation
DISPLAY Home / introduction; DISPLAY About me, education and hobbies; DISPLAY Technical skills; DISPLAY Projects and achievements; DISPLAY Contact information
APPLY CSS presentation and responsive rules
WHEN a navigation link is selected, MOVE to its matching section
END
```
