# Bakery and Cake Shop Website – Test Cases

**Testing type:** Manual functional and visual testing.

| Test ID | Test step | Expected result | Verification |
|---|---|---|---|
| TC01 | Open index.html | Bakery homepage and hero banner appear | Manual visual check |
| TC02 | Select Our Treats | Product cards are reached | Images, descriptions and prices appear |
| TC03 | Select Offers | Discount message and code appear | Offer section is visible |
| TC04 | Select Gallery | Gallery images are displayed | Images have alternative text |
| TC05 | Select Contact | Address, hours and contact details appear | Email link is available |
| TC06 | Resize browser to mobile width | Products and gallery stack vertically | Content remains readable |

**Important:** These are test procedures and expected results, not claimed pass results. Perform them in a browser and record Pass/Fail. This is a static HTML/CSS demonstration; it does not store or submit user data.
