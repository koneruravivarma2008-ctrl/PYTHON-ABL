# Bakery and Cake Shop Website – Algorithm and Pseudocode

## Aim
Introduce a bakery, display products and prices, show offers, present a gallery and provide contact details.

## Algorithm
1. Start.
2. Create the HTML document and link the external CSS file.
3. Create the header and navigation links.
4. Add the main page sections: Hero / welcome banner, Best-selling products, Promotional offer, Image gallery, Address, opening hours and contact.
5. Apply CSS colors, typography, images, dimensions, borders, margin, padding and responsive layout.
6. Use anchor links to navigate to page sections.
7. Open the page in a browser and check links, images and layout.
8. Stop.

## Pseudocode
```text
BEGIN
LOAD HTML document and external CSS
DISPLAY header and navigation
DISPLAY Hero / welcome banner; DISPLAY Best-selling products; DISPLAY Promotional offer; DISPLAY Image gallery; DISPLAY Address, opening hours and contact
APPLY CSS presentation and responsive rules
WHEN a navigation link is selected, MOVE to its matching section
END
```
